# Claude Code Guidelines

* **Role**: implementation, testing, evaluation, documentation generation.
* **Restrictions**: must not create commits, push, or modify planning files.
* **Allowed actions**: create/modify implementation files, run tests, generate docs.
* **Prohibited**: modify PROJECT.md, DECISIONS.md, planning artifacts.

## Workflow
1. Receive approved planning.
2. Implement Phase?00 tasks.
3. Run tests.
4. Report results.
